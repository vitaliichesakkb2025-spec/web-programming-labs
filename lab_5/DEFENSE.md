# Лабораторна №5 — короткий захист

1. **Що завантажує браузер?** HTML, CSS, JS та інші файли з серверів/CDN хостингу.
2. **Перевага Git?** Автоматичні збірки та оновлення після комітів, історія змін.
3. **Що після git push?** GitHub оновлюється, Vercel отримує подію, завантажує код, встановлює залежності, запускає build і публікує файли.
4. **Root Directory?** Коренева папка конкретного сайту всередині GitHub-репозиторію.
5. **HTML проти Vite?** HTML одразу готовий, Vite збирає модулі в оптимізовані файли.
6. **Output Directory?** Папка готових файлів; у Vite це `dist/`.
7. **Production / Preview?** Production для основної гілки, Preview для інших гілок і pull request.
8. **Чому немає node_modules у Git?** Пакети відновлюються через npm і lockfile; папка велика.
9. **Звідки HTTPS?** Vercel налаштовує TLS-сертифікати через центр сертифікації та оновлює їх.
10. **Де шукати помилку?** Project → Deployments → Build Logs: там видно етап збірки і повідомлення про помилку.

**Показати на захисті:** дві папки `lab_5`, два Vercel Projects, різницю Root Directory, `package.json`, `dist`, коміт зміни `DEPLOY v1` → `v2` та оновлені публічні сайти.
