# Короткий захист лабораторної №4

**Вступ (30 секунд):** «У лабораторній №4 я додав JavaScript до резюме: збереження відомостей про браузер у localStorage, асинхронне отримання коментарів із JSONPlaceholder для варіанта 24, модальну форму після 60 секунд і перемикання денного/нічного режиму. У React використав useState та useEffect, окремі компоненти Reviews, ContactForm і Footer».

## Контрольні питання (частина 1)

1. **JavaScript** — мова програмування для логіки й інтерактивності вебсторінок.
2. **ECMAScript** — стандарт мови, JavaScript — його реалізація.
3. **Підключення** — inline обробник, тег `<script>`, зовнішній файл через `<script src="...">` (або модуль `type="module"`).
4. **Змінні** — `const`, `let`, застаріле `var`.
5. **Типи** — string, number, bigint, boolean, undefined, symbol, null, object.
6. **null і undefined** — `null` задане значення «порожньо», `undefined` означає відсутність присвоєного значення.
7. **Перевірити тип** — `typeof value`; для масиву `Array.isArray(value)`.
8. **Порівняти** — `===` і `!==` без неявного приведення типів.
9. **Тернарний оператор** — `умова ? значення1 : значення2`.
10. **Умови** — `if`, `else if`, `else`, `switch`.
11. **Цикли** — `for`, `while`, `do...while`, `for...of`, `for...in`.
12. **break / continue** — вийти з циклу / пропустити поточну ітерацію.

## Контрольні питання (частина 2)

1. **Навіщо useEffect?** — виконувати побічні ефекти після рендеру: запити, таймери, роботу зі сховищем.
2. **Порожній `[]` у useEffect?** — ефект запускається після монтування; у режимі розробки StrictMode може повторно запускатись для перевірки.
3. **Чому useState?** — оновлення стану викликає повторний рендер, звичайна змінна — ні.
4. **Не відкривати повторно форму?** — записувати закриття у sessionStorage, очищувати таймер у cleanup.
5. **DOM vs React?** — імперативно безпосередньо змінюємо DOM, React декларативно обчислює інтерфейс зі стану.

## Приклади по коду

- `localStorage.setItem('kb208.lab4.system', JSON.stringify(info))` — запис даних браузера як JSON-рядка.
- `fetch('https://jsonplaceholder.typicode.com/posts/24/comments')` — асинхронний GET для варіанта 24.
- `setTimeout(() => setIsOpen(true), 60000)` — форма через хвилину.
- `new Date().getHours()` і `hour >= 7 && hour < 21` — визначення теми.
- `comments.map(comment => <article ... />)` — відображення масиву коментарів у React.

**Важливо:** навчальні коментарі JSONPlaceholder не є реальними відгуками роботодавців. Надсилання Formspree справжнє лише після налаштування особистого endpoint.
