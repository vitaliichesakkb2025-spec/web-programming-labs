# Лабораторна робота №4 — JavaScript

**Дисципліна:** «Технології вебпрограмування»  
**Виконав:** Чесак Віталій Володимирович, КБ-208 · **варіант 24**

Продовження резюме з лабораторної №3: збережено власний темний дизайн та адаптивне оформлення. Додано JavaScript-функції за методичкою. Роботи №2 та №3 залишаються незалежними.

## Структура

| Частина | Що відкрити | Як працює |
|---|---|---|
| 1. HTML/CSS/JavaScript | `lab_4/index.html` | Зовнішній JS-модуль `script.js`; `form-config.js`; стилі `styles.css` |
| 2. React + Tailwind | `lab_4/lab_2_react/` | `useState`, `useEffect`, `Reviews`, `ContactForm`, `Footer` |

## Реалізовано за методичкою

1. **Інформація про ОС та браузер:** отримання через Navigator, Screen і Window API; `JSON.stringify` для запису в `localStorage`, `JSON.parse` для читання; розгорнутий блок у футері.
2. **Відгуки:** `fetch('https://jsonplaceholder.typicode.com/posts/24/comments')`. Для React використовуються `useEffect` і `useState`; порядок результатів з API збережено через `map`. Дані **тестові**, не від реальних роботодавців.
3. **Форма:** через 60 000 мс відкривається модальне вікно з ім'ям, email, телефоном, повідомленням та кнопкою «Надіслати». Є кнопка для ручного відкриття та «Закрити». Після закриття повторне автоматичне відкриття в тій самій вкладці вимикається через `sessionStorage`.
4. **Тема:** автоматично **світла 07:00–20:59**, **темна 21:00–06:59**, кнопка ручного перемикання. Після ручного вибору він зберігається до перезавантаження сторінки.

## Частина 1: запуск HTML

У VS Code відкрий корінь репозиторію й файл `lab_4/index.html` через **Open with Live Server**. Важливо: модуль `type="module"` і `localStorage` можуть працювати інакше з `file://`, тому потрібен локальний HTTP-сервер (Live Server).

## Частина 2: React

В терміналі VS Code з кореня репозиторію:

```powershell
cd lab_4/lab_2_react
npm install
npm run dev
```

Відкрий URL Vite, зазвичай `http://localhost:5173`. Для збірки: `npm run build`.

## Обов'язково під'єднати Formspree

Неможливо відправити повідомлення на твою пошту, не створивши форму **під твоїм акаунтом**.

1. Зареєструйся на https://formspree.io/ та підтвердь email, на який мають приходити листи.
2. Створи нову форму й скопіюй endpoint вигляду `https://formspree.io/f/abcdefgh` (це **приклад**, не справжня адреса).
3. Встав свій endpoint **у два файли**:
   - `lab_4/form-config.js`
   - `lab_4/lab_2_react/src/form-config.js`
4. Збережи, перезапусти сайт, відправ тестовий лист із кожної частини й перевір вхідну пошту та форму у Formspree.

**До налаштування endpoint форма показує повідомлення замість удаваного надсилання.** Не вводь справжні персональні дані у навчальний тест, якщо це не потрібно.
