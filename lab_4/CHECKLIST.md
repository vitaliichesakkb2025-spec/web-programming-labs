# Лабораторна №4 — кроки до здачі

- [ ] **Частина 1:** відкрий `lab_4/index.html` через Live Server, перевір дизайн.
- [ ] У футері розгорни «Інформація про браузер та ОС», покажи запис `kb208.lab4.system` в DevTools → Application → Local Storage.
- [ ] У розділі «Відгуки» мають з'явитися коментарі **публікації №24**. Якщо помилка — перевір інтернет і консоль браузера.

- [ ] Перевір у F12 мобільну ширину **390 px**, відсутність горизонтального прокручування.
- [ ] Зроби справжні скриншоти: HTML з відгуками; localStorage/Footer; форма; перемикання теми; React; мобільна версія; `npm run build`; тест листа Formspree (без приватних даних).
- [ ] Встав скриншоти у звіт DOCX, зміни статуси «потрібно перевірити» на реальний результат і збережи фінальний PDF.
- [ ] Якщо редагував код/звіт — `git add lab_4`, `git commit -m "Complete lab 4 tests"`, `git push origin main`. Не додавай `node_modules` і `dist`.
