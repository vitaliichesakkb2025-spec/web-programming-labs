# Лабораторна робота №2 — HTML та React

**Чесак Віталій Володимирович · КБ-208**

## Завдання
- **Частина 1:** `index.html` — персональне HTML5-резюме без CSS і JavaScript.
- **Частина 2:** `lab_2_react/` — те саме резюме, відтворене React-компонентами на базі Vite.

## Запуск
1. Для першої частини відкрийте `index.html` у браузері.
2. Для другої частини перейдіть до `lab_2_react`, виконайте `npm install` та `npm run dev`.
3. Відкрийте локальну адресу Vite, яку показує термінал.
4. Для перевірки структури компонентів відкрийте React Developer Tools → Components.

## Структура
- `index.html` — семантичне HTML-резюме.
- `lab_2_react/src/App.jsx` — головний React-компонент.
- `lab_2_react/src/components/` — Header, About, Skills, Contacts, Education, Projects, Footer.
- `lab_2_react/src/App.css` — оформлення другої частини.

Результати перевірки та скриншот React DevTools наведено у звіті до лабораторної роботи.
