# React-частина лабораторної роботи №2

1. Переконайтеся, що встановлені Node.js та npm: `node -v`, `npm -v`.
2. У папці `lab_2_react` виконайте `npm install`.
3. Виконайте `npm run dev` і відкрийте URL з термінала.
4. Для перевірки збірки виконайте `npm run build`.
5. Для дерева компонентів встановіть React Developer Tools та відкрийте F12 → Components.

Точка входу: `src/main.jsx`. Кореневий компонент: `src/App.jsx`.
Дані резюме розділено на Header, About, Education, Skills, Projects, Contacts, Footer.
CSS використано лише в React-частині, HTML-частина не містить стилів.
