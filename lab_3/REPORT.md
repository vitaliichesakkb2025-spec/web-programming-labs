# Що зроблено — лабораторна №3

## Мета
Опанувати три способи підключення CSS, селектори, блокову модель, Flexbox / Grid, адаптивність та Tailwind CSS 4 у React.

## Рішення для макета

П'ять розділів резюме залишено з лабораторної №2, щоб можна було порівняти оформлення. Темна основа з блакитними акцентами, навігація за якорями, картки у два стовпці на широкому екрані та в один стовпець на вузькому.

## Частина 1

- Зовнішні правила — `styles.css`; один приклад `<style>` у `index.html` і один inline `style=`.
- Селектори: `body`, `.panel`, `#contacts`, `a[target="_blank"]`.
- Стани `:hover`, `:focus-visible`, `:active`.
- Блокова модель: `box-sizing`, `margin`, `padding`, `border`.
- `display: grid` для карток, `display: flex` для навігації та кнопок.
- Медіазапити `900px` і `580px`.

## Частина 2

React-компоненти оформлено utility-класами Tailwind 4. Підключення: `tailwindcss`, `@tailwindcss/vite`, Vite-плагін та `@import "tailwindcss";`. Кольори визначено через `@theme`.

## Перевірка

HTML/CSS-сторінка перевірена на комп’ютері та при ширині **390 px**: картки стають у одну колонку, горизонтального прокручування немає.

React/Tailwind **успішно запущений у браузері** (скриншоти перевірки від 28.10.2026). Команда `npm run build` завершилася без помилок: Vite 6.4.5, **36 modules transformed**, **built in 797ms**, створено `dist/`. Підсумковий звіт Word/PDF містить ці скриншоти.

## Висновок

HTML-сторінку стилізовано звичайним CSS з адаптивним макетом. Структуру React-компонентів збережено, стилі перенесено в Tailwind. Локальна перевірка React і production-збірка успішні; результати зафіксовано у звіті.
