# Лабораторна робота №3 — Робота з CSS

**Дисципліна:** Технології вебпрограмування  
**Виконав:** Чесак Віталій Володимирович, КБ-208.

## Мета
Опанувати CSS для оформлення вебсторінок, блочну модель, селектори, псевдокласи, адаптивну верстку та застосування Tailwind CSS в React.

## Частина 1: HTML та CSS
Створено адаптивне резюме з окремим файлом `styles.css`.
- Застосовано зовнішні, внутрішні та вбудовані стилі.
- Використано селектори елементів, класів, ідентифікаторів та атрибутів.
- Реалізовано псевдокласи, `flex`, `grid`, відступи, рамки та медіазапити.
- Перевірено вигляд на широкому і мобільному екранах.

**Файли:** [`index.html`](index.html), [`styles.css`](styles.css).

## Частина 2: React + Tailwind CSS
На основі React-резюме з лабораторної №2 створено версію з Tailwind CSS 4.
- Tailwind підключено через `@tailwindcss/vite` і `@import "tailwindcss";`.
- Оформлено компоненти через utility-класи, додано адаптивність.
- Збережено компонентну структуру (Header, About, Education, Skills, Projects, Contacts, Footer).

**Файли:** [`lab_2_react/`](lab_2_react/).

## Перевірка
HTML/CSS було перевірено на десктопній і мобільній ширині. React/Tailwind **потребує локального `npm install` і перевірки `npm run build`**: у середовищі підготовки npm registry був недоступний.

## Висновок
У ході виконання роботи освоєно основи каскадних таблиць стилів та адаптивну верстку, а також спосіб стилізації компонентів React за допомогою Tailwind CSS.

Повноформатний звіт із титульною сторінкою за зразком університету доступний в окремому архіві лабораторної №3.
