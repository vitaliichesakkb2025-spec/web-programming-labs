# Лабораторна №3 — Робота з CSS

**Дисципліна:** Технології вебпрограмування  
**Студент:** Чесак Віталій Володимирович, КБ-208.

## Ідея

Дві версії одного резюме: HTML + звичайний CSS і React + Tailwind CSS 4. Стилістика — темно-синя основа, блакитні заголовки, невеликі теплі акценти. Макет побудовано так, щоб секції були зручні і на ноутбуці, і на телефоні.

## Частина 1 — HTML + CSS

- [index.html](index.html) — структура, п'ять розділів і навігація за якорями.
- [styles.css](styles.css) — основні правила, Grid, Flexbox, Box Model, селектори та медіазапити.
- Для демонстрації вимоги методички також використано один внутрішній `<style>` і один inline `style=`.
- При ширині до 900 px картки переходять в одну колонку; до 580 px змінюються відступи та розміри тексту.

**Запуск:** відкрити `lab_3/index.html` у браузері або через Live Server.

## Частина 2 — React + Tailwind CSS 4

- [lab_2_react/](lab_2_react/) — копія React-структури з лабораторної №2, щоб не змінювати попередню роботу.
- Плагін `@tailwindcss/vite` у `vite.config.js`, імпорт `@import "tailwindcss";` у `src/index.css`.
- Компоненти `Header`, `About`, `Skills`, `Education`, `Projects`, `Contacts`, `Footer` оформлено utility-класами.

```powershell
cd lab_3/lab_2_react
npm install
npm run dev
```

Для перевірки production-збірки зупинити сервер (`Ctrl+C`) і виконати `npm run build`.

## Статус перевірки

- HTML/CSS: перевірено на ширині **1440 px** та **390 px**, без горизонтального прокручування.
- React/Tailwind: **потрібна локальна перевірка** через `npm install`, `npm run dev`, `npm run build`. Не видаємо ці кроки за вже виконані.
