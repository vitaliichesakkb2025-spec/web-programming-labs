# Лабораторна №3. Робота з CSS

Чесак Віталій, КБ-208

Резюме з лабораторної №2, оформлене двома способами.

## Частина 1. HTML + CSS

- `index.html`, `styles.css`
- Основні стилі у зовнішньому файлі, плюс по одному прикладу `<style>` та `style=""`.
- Селектори тегів, класів, ID, атрибутів, псевдокласи `:hover`, `:focus-visible`, `:active`.
- Секції розкладені через Grid, навігація і кнопки через Flexbox.
- Медіазапити на 900 px і 580 px, на вузькому екрані картки йдуть в одну колонку.

Запуск: відкрити `index.html` через Live Server.

## Частина 2. React + Tailwind CSS 4

Папка `lab_2_react` (копія проєкту з лаби №2). Tailwind підключений через плагін `@tailwindcss/vite`, компоненти оформлені utility-класами.

```
cd lab_3/lab_2_react
npm install
npm run dev
```
