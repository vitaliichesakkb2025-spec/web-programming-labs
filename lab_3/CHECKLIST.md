# Лабораторна №3 — що зробити перед здачею

Цей файл можна використовувати як власний список перевірок у VS Code.

- [ ] **Оновити репозиторій:** відкрити папку `web-programming-labs` у VS Code, виконати `git pull origin main`.
- [ ] **Перша частина:** відкрити `lab_3/index.html` через Live Server; перевірити навігацію, всі 5 секцій, посилання та відсутність горизонтального скролу.
- [ ] **Адаптивність:** F12 → режим телефона, ширина 390 px; перевірити одну колонку.
- [ ] **Друга частина:** у терміналі `cd lab_3/lab_2_react`, потім `npm install` і `npm run dev`. Відкрити адресу, яку покаже Vite.
- [ ] **React:** перевірити всі компоненти, мобільне відображення, наведення та посилання. Зробити власний скриншот.
- [ ] **Збірка:** зупинити Vite через Ctrl+C, виконати `npm run build`; переконатися, що збірка завершилась без помилок.
- [ ] **Звіт:** відкрити Word, замінити примітку «ще треба перевірити» на фактичні результати після тесту; додати скриншот React. Експортувати остаточний PDF.
- [ ] **Особисті правки:** перевірити інформацію про себе, за потреби переписати 2–3 фрази власними словами і знати, де знаходяться CSS / JSX.
- [ ] **GitHub:** якщо файли змінювалися, виконати `git add lab_3`, `git commit -m "Finalize lab 3"`, `git push origin main`. Перевірити, що файли видно у браузері.
- [ ] **Захист:** вміти показати `styles.css`, `vite.config.js`, `src/index.css`, `App.jsx` та коротко пояснити різницю між CSS і Tailwind.

У репозиторій **не додавати `node_modules/` та `dist/`**.

Якщо `npm install` видасть помилку — збережи текст помилки й виправ причину, не позначай React як перевірений.
